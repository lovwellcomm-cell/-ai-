# 产品文档：年报 AI 研究助手

## 一句话

帮普通投资者读懂上市公司的定期报告，并且**每个数字都能点回原页核对**。

## 用户和问题

**目标用户**：自己看财报做决定的个人投资者。会看营收、利润，但很少去翻附注、现金流量表和那些散户最容易漏看的小字。

他们读财报时遇到的问题：

| 问题 | 现状 |
|---|---|
| 一份年报两三百页，找一个数要翻很久 | 用 Ctrl+F 搜关键词，同一个科目在报告里出现十几次，分不清哪个是合并报表口径 |
| 看到了数，不知道说明什么 | 资产负债率 56% 算高还是低？应付票据涨了两倍意味着什么？ |
| 通用 AI 能读 PDF，但数字不敢信 | 会编数、读错列、把九个月的累计数和十二个月比，而且没法核对 |
| 风险藏在小字里 | 审计意见带强调事项、大股东质押、客户高度集中，这些不在首页 |

## 定位

**可核对的财报助手。** 和通用 AI 读 PDF 的区别不在于「答得更多」，而在于**答出来的数能信**：

1. 每个论断带引用编号，点开看原文、翻 PDF 原页；
2. 回答里的表格逐格核对出处，找不到出处的数字标出来；
3. 关键财务数字由程序抽取、勾稽核对，不交给模型；
4. 答不出就说「未找到」，不编。

## 做什么、不做什么

| 做 | 不做 | 为什么不做 |
|---|---|---|
| 解读定期报告里写了什么 | 荐股、给买卖建议 | 在国内给出投资建议需要证券投资咨询资质；而且用户要的是「看懂」，不是「替我决定」 |
| 用报告里的数做对比和计算 | 预测股价、预测业绩 | 预测没法核对，和「每个数都能核对」的定位冲突 |
| 外部行情、行业动态作为参考 | 实时行情 | 不是这个产品的长项，行情软件做得更好 |
| 联网补充公开信息 | 把网上的说法混进报告结论 | 联网内容单独成块、标「未经报告核验」，每条带日期和来源 |

## 关键取舍

这些是做的过程中真实面临的选择，以及为什么这样选。

**1. 对不上的数宁可不出。**
三张表抽完先做勾稽自检（资产 = 负债 + 所有者权益等），哪张对不上就不展示哪张，并说明原因。主要会计数据用公司披露的增减比例复算，对不上的行丢掉。
用户看到「这张表没展示」最多觉得不完整；看到一个错数，整个产品的信任就没了。

**2. 关键数字交给程序，语言交给模型。**
指标卡、财报体检、三表速读都不调模型：零成本、结果稳定、可以写单元测试。模型负责理解问题、组织语言、找原因。程序算出的指标进回答时，要求模型注明「按公式计算」，不能说成公司披露的数。

**3. 体检打灯，速读不打灯。**
财报体检回答「有没有雷」，每一项都有公开的判断标准，所以亮红黄绿灯。三表速读回答「钱从哪来、花到哪去」，只讲结构和变化：资产负债率 56% 对制造业和对软件公司意义完全不同，硬打灯会误导。

**4. 时间概念要对。**
用户说「最新财报」「目前负债率」，指的是已经披露的最近一期，不是当前年份的年报（11 月问「2026 年报」，它还没出）。报告期还没结束的报告直接说明最晚何时披露，不去白找一趟。

**5. 复核要花时间，所以只为大问题回退。**
复核器只为三类问题判不通过：要点没答到、说法没依据、片段里有却说「未找到」。措辞、格式、篇幅不判。回退一次多花约 20 秒，最多一次，整轮有时间预算。

**6. 跨口径的错，提示词拦不住，要程序查。**
「前三季度营收较去年全年下降 27%」这种句子，每个数字都有出处，逐格核对和复核模型都看不出错。所以单独写了跨口径检查，查出来直接判重写。

## 怎么衡量

| 指标 | 怎么测 | 当前 |
|---|---|---|
| 关键数字答对 | 端到端评测，期望数字取自报告原文 | 37 题全部合格 |
| 不编数 | 回答里找不到出处的数字个数 | 每轮评测统计，只看相对变化 |
| 拦得住错误 | 往正常回答里注入错误，看复核器拦不拦 | 30/31 |
| 程序抽取准确 | 勾稽自检 + 和另一张表交叉核对 + 人工核过的答案 | 三表 66/66、110/110、20/20；体检 96/96 |
| 速度 | 端到端评测耗时中位数 | 约 20–30 秒（含复核） |

数字取自最近一次上线评测。评测题目由作者自建，覆盖约 15 家公司，用真实模型跑，结果会有波动。每次上线的记录、判错的例子见站内的[评测页](https://xlyzp-ai.streamlit.app/?eval=1)。

## 如果作为真实产品

**谁会付费。** 散户通常只为荐股信号付费，而这正是我们不做的。愿意为「数字准、能给出处」付费的，是每天要写东西、数字必须对的人：

| 人群 | 痛点 | 可能付费的功能 |
|---|---|---|
| 认真的价值投资者 | 自选股多，财报季看不过来 | 关注列表 + 新报告出来自动出变化摘要 |
| 财经作者、写研报的学生和实习生 | 数字要准、要能给出处 | 导出带页码的研究底稿（Excel / Word） |
| 高校财报分析课、CPA / CFA 备考 | 需要拿真实报告练手 | 教学版：三表速读 + 勾稽讲解 |
| 小型私募、投顾的研究助理 | 同行对比做表费时间 | 同行对比表、批量体检 |

**成本。** 体检、速读、三表数据不调模型，边际成本接近零；问答用 DeepSeek，单次成本很低。模式可以是免费额度 + 付费功能（关注数量、导出、批量）。

**风险。**
- 竞品：同花顺、东方财富有结构化数据源和免费 AI 助手；通用 AI 也能读 PDF。护城河不在数据，在「可核对」和财务口径的严谨。
- 数据源：现在从 PDF 解析，规模化需要接入结构化财务数据，PDF 解析留作核对和出处。
- 合规：始终不给投资建议，联网信息标明未经核验。

## 路线图

已上线：问答（引用 + 原页 + 逐格核对 + 复核）、自动找报告、四种报告期、多年趋势和单季序列、跨报告回答、财报体检、几件大事、行业动态、三表速读（含进回答）、[公开评测页](https://xlyzp-ai.streamlit.app/?eval=1)。

接下来（按优先级，每项开工前再确认）：

1. **带出处的导出**：回答、体检、三表速读导出成 Excel，每个数旁边带「年报第 n 页」。成本低、价值最具体，最可能让人愿意付费。
2. **关注列表 +「这期变了什么」**：关注几家公司，新报告出来自动出变化摘要（三表变化大的科目、体检变了灯的项、风险章节新增的内容）并推送。需要定时任务和推送，要先解决托管平台跑不了后台任务的问题。
3. **同行对比**：同行业 3–5 家公司的关键指标放一张表，每格可翻原页。
4. **承诺兑现检查**：去年年报说今年要做的事，做到了吗。
5. **问询函 / 业绩预告排雷**：交易所的问询函是信号很强的风险提示，和财报体检放在一起。
6. **分享长图**：三表速读卡、体检卡一键生成带页码的图片，方便分享。
